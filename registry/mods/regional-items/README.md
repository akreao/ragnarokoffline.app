# Regional Items (client text)

Since 1.6.4 the server knows 2,827 regional items from iRO, kRO, jRO, bRO and
other servers (rathena#51). Your client only names the ones its own tables
know. This mod adds the rest, as `itemInfo` add-on tables:

- **kRO-only items** (237): English names and descriptions, translated from
  kRO's text. Their sprites come from a kRO fallback GRF.
- **iRO's wording** for the 8 official items that now follow iRO's
  descriptions (Fifth Element, Mask of Ifrit, Valkyrie Curse Blight, ...).
- **No more "Unknown Item"** for 3,582 items the server has but no client table
  names (e.g. jRO's Ancient Royal Scepter 550095): rAthena's name, a sprite
  borrowed from an item with the same look or type, and its stats as the
  description.

Client text only; the items themselves are in the server.
