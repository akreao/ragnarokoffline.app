Everything in your GRFs, as the game reads it — with any file a mod replaces shown as the mod has it. Pick a file on the left, or search for one.

  • Copy to mod puts the file in one of your mods (or a new one) at the path the client asks for. A mod's copy replaces the GRF's.

  • Mod changes reach the game after Settings → Mods → Apply.
