The Imperial Guard job change quest and the Memorial Dungeon window, a way for mod scripts to tell which client a player has, and fixes for Episode 18 and 19 quests, the skill window, Druid effects, instant map changes and mod status icons.

## New
- **Imperial Guard's 4th job change:** the Imperial Guard job change quest is in the game. It starts with the King's Knight in Prontera Castle, takes you to the Knight of Devotion and the Knight of Armament in Prontera, and ends in two one-on-one rounds in the Tourney Hall of Trials. Navigation knows its NPCs. Thanks @MondoTruth. (rathena#76 via #683)
- **Memorial Dungeon window:** creating or entering an instance now shows the Memorial Dungeon window, as the official client does, with its standby position, entry deadline or time limit, and a button to destroy it. Thanks @MondoTruth. (roBrowserLegacy#205 via #684)

## Modding
- **Scripts can tell which client a player has:** a mod's NPC script can call `F_ClientInfo` to learn the host's main client and fallback GRF, and their dates, so a feature that needs art from the fallback (Druid sprites on an iRO host with a kRO fallback, say) no longer has to be switched off for every host. (#682)
- **`stock_checks = false` also skips a skill's target checks:** a Lua `skill()` hook that turns off the stock checks now also gets past the skill-specific checks on the target, such as pre-renewal Back Stab's "only from behind", so a mod can let a skill hit another way. The skill's own effect may still check again. Thanks @BlaXun. (rathena#78 via #690, #689)

## Fixes
- **Episode 18's villa flower door opens:** progress bars finished a moment too early, so the server read them as cancelled. The 5-second flower device before the Villa of High Priest's last two bosses never opened the door, which blocked the main quest. (roBrowserLegacy#204 via #679)
- **Episode 19 step 5 can be finished:** clicking the Book-shaped Box beside Nihil now opens his dialog, where before the box hid him and he couldn't be clicked. Thanks @LilArt420. (rathena#72 via #681)
- **The skill window opens on your current job's tab:** after logging in or changing job, the skill window showed the 1st job's skills. It now opens on the tab for the job you are. Thanks @MondoTruth. (roBrowserLegacy#206 via #685)
- **Druid skill effects fly at their target:** Cutting Wind, Shooting Feather, Pinion Shot, Quill Spear, Sharpen Gust and Roaring Piercer now start at the Druid and fly at the target on whichever side it stands, Low Flight's raptor sweeps in from the Druid's side, and Sharpen Hail's shot lands on the target. Each Druid effect is drawn once instead of twice, and is no longer cut off by the ground. Thanks @akreao. (roBrowserLegacy#207, #208 via #686)
- **Instant map changes are really instant:** with Map changes set to instant, a teleport on the same map (Teleport, Fly Wing, `@warp`) no longer flashes a black frame before the view moves. Thanks @LilArt420. (roBrowserLegacy#209 via #688)
- **Mods with their own status icons no longer stop the login at 97%:** on the iRO client, a mod that adds status icons made the login stop at 97%, because iRO's icon list refuses new names. The mod's icons are now added, and a status icon file that fails to load no longer holds up the login. Thanks @BlaXun. (roBrowserLegacy#210 via #691)
