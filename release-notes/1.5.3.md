A hotfix for 1.5.2 servers that couldn't start on some Macs, the population playing by player rules (spending SP, resting, drinking potions and fighting at their level), selling trips for full bags, and a sitting character in the skill tree, plus fixes for clicking the map after a trade, companion growth, the population in four dungeons and skill tree highlights.

## New
- **The population plays by player rules:** field shells now spend SP on their skills and sit down to rest when they run low, carry and drink potions for their level, and take their level from the map they spawn on, with the stats a character of that level would really have. That makes most shells noticeably weaker than before, but they look and fight like the players around them. Companions can set their own rest marks with `@companion rest` or in the Companions window's Battle tab. Thanks @akreao. (#463, #469, #470, #472)
- **Selling trips:** an ambient shell whose bag is full now goes off to sell instead of carrying on overweight. Thanks @Dizzzlectic. (#464, fixes #458)
- **Sitting in the skill tree:** the expanded skill window now draws your character sitting in its lower left and looking around, the way the official client does. Thanks @akreao. (roBrowserLegacy#92 via #474)

## Modding
- **Shell shops in the database:** with the new `population_engine_list_stalls` setting on (it's off by default), the population's vending stalls and buying stores are written to the shop tables, so a mod that searches shops can find them. Thanks @rhewid. (#466)

## Fixes
- **Servers that couldn't start in 1.5.2:** on some installs, including a fresh install on macOS 13, 1.5.2 couldn't start the game at all: every start ended with "ragnarok-map stopped during startup: Couldn't connect with uname='ragnarok' (script SQL: 'ragnarok_mods')". The read-only database login that mods' scripts use is now only used once the database confirms it can read the game's tables; otherwise the server starts without it, and mods' scripts query with the server's own login for that run. (#475)
- **Clicking the map after a trade:** after a trade, or any drag of an item out of a window, the map could stop taking clicks and the hand cursor stayed until you pressed Esc. Thanks @akreao. (roBrowserLegacy#90 via #465)
- **Installing a mod:** the confirmation box shown when installing a mod no longer prints its release notes, cut off at 700 characters with the Markdown showing. The Updates tab and the mod's page still link them. Thanks @MondoTruth. (#462)
- **Companion growth:** a companion at 3rd job or later got its extra stat points about ten times a second instead of once per level, so it reached its profile's maximum stats right away, whatever its level. It now gets them once for each level it gains. A companion that already reached those stats keeps them. Thanks @akreao. (#468)
- **Population in four dungeons:** Geffen Dungeon 1–2 and Payon Cave 3–4 no longer fill with low-level 1st-class players among monsters far above them. Those dungeons now hold the mid-tier classes (Wizards, Hunters, Bards and Dancers, Assassins), and every other map keeps its numbers. Thanks @akreao. (#471)
- **Skill tree highlights:** the expanded skill tree marked every skill the server lets you raise, even with no skill points left, and the marks never changed afterwards. A skill is now marked only while you have points to put into it, the way the official client does it. Thanks @akreao. (roBrowserLegacy#91 via #473)
