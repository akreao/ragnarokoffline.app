The app can now update itself, the stylist gets a proper window, and Airship Assault gains its Normal and Hard encounters.

## New
- **The app updates itself:** new versions now download in the background, and **Settings → General → Updates** shows the status with a **Restart to install** button. Nothing installs until you ask, unless you turn on installing at quit. This is the first release that carries the update files, so the next one is the first that installs itself; anything older updates by hand once more. (#606)
- **A new stylist window:** the stylist now shows a preview of your character, a picture grid for each look and an order summary with prices, and NPCs that offer it can take Zeny or a coupon. Picking a clothes colour now buys the colour you picked, not the one before it. Thanks @MondoTruth. (#596)
- **Airship Assault, Normal and Hard:** on renewal, the Airship Assault instance now has its Normal and Hard encounters, with their monsters, skills and achievements. Thanks @Dizzzlectic. (rathena#46 via #607)

## Modding
- **Stylist prices from scripts:** a mod can turn on the `stylist_script_costs` server extension and set each look's price from its NPC script, in Zeny or a coupon, instead of using `stylist.yml`. With it on, an order is checked as a whole before anything is charged. It's off by default. Thanks @MondoTruth. (rathena#47 via #49, #608)

## Fixes
- **Chat window layout:** the chat window now reaches the screen edge when snapped to it, the input bar no longer shifts when you start typing, and the tab borders and scrollbar line up. Enter, the chat-mode button and an empty message all switch the input the same way, including in the minimized chat. Thanks @Dizzzlectic. (roBrowserLegacy#149 via #595)
- **Alternative outfits from the stylist:** buying the alternative outfit now changes it instead of taking the ticket for nothing, and baby 3rd and 4th jobs can wear their 3rd job's outfit. Thanks @MondoTruth. (rathena#48 via #598)
- **Random options against Normal and Boss enemies:** the two random options that reduce damage from Normal or Boss enemies now reduce physical damage only, as their descriptions say, instead of magic damage too. Thanks @Dizzzlectic. (rathena#36 via #608)
- **Non-critical damage random options:** the random options for more non-critical damage dealt and less non-critical damage taken (255 and 256) now work. Thanks @Dizzzlectic. (rathena#40 via #609)
- **Report a problem keeps the latest client log:** in a long session the client log used to stop at 4 MB, losing the part just before a problem. It now starts a new file and keeps the previous one beside it. Thanks @akreao. (#604)
- **Sharing:** when a friend's game link drops, the log now says which side ended it and when data last flowed each way. Thanks @akreao. (#603)
- **The English quest table is sent once** instead of twice. The client fetches its translated files again once after the update. Thanks @akreao. (#601)
