The server learns kRO's Druid line and thousands of regional items, Mega Booster joins the mod registry, and the asset server reads newer kRO archives.

## New
- **The Druid line (server side):** the server now knows kRO's newest jobs: Druid, Karnos and Alitea, with their baby jobs, 84 skills and the Werewolf / Wereraptor shapeshifts (Renewal only). Alitea gets trait stats and AP like the other 4th jobs. The shapeshift bodies and skill effects come with the next client update, and the art needs a 2026 kRO `data.grf` set as the fallback GRF. This is upstream rAthena's work in progress, so expect rough edges. Thanks @LilArt420. (rathena#50 via #613)
- **Regional items:** 2,827 items from iRO, kRO, jRO, bRO and other servers that the renewal item database was missing now exist, with 814 set bonuses. `@item` can create them, and boxes such as the Overseas Care Packages open and give their contents. Their effects are translated from the client's descriptions; effects that couldn't be read are left out, and about 430 boxes whose contents weren't available can't be consumed yet. Eight official items, such as Fifth Element and Mask of Ifrit, now follow iRO's descriptions. Thanks @LilArt420. (rathena#51 via #621)
- **Mega Booster in the registry:** a new Renewal mod brings kRO's Mega Booster promotion. New characters get a Booster Box from the Booster Guide in Izlude, and the Booster Call summons Lime Evenor for booster shops, Lv 1-80 hunts, Booster Missions, enchants, Level Up Tickets and milestone rewards. It also adds the Job Agent, Reset Service and Booster Exchanger in Prontera's Convenience Center. It installs and updates from its author's own releases. Thanks @akreao. (#619)
- **Newer kRO archives:** the asset server now reads entries that the newest kRO `data.grf` stores in Gravity's protected format, so more of its files can be served. Thanks @Dizzzlectic. (RemoteClient#11 via #622)

## Fixes
- **Mods with era-specific tables:** a mod that ships the same table in `db/` and in its renewal or pre-renewal folder no longer wipes out the entries earlier mods added to that table. The bundled exp-card did this in pre-renewal, so other mods' items disappeared. Thanks @BlaXun. (#612)
- **Names with accented letters:** files whose Korean-encoded names the client spells with Western accented letters, such as some French item names, are now found in the GRF instead of missing. Thanks @akreao. (RemoteClient#15 via #622)
- **Less work serving the client:** the asset server sends the client's precompressed files as they are and keeps the compressed form of game assets, so loading is lighter on the CPU. Thanks @akreao. (RemoteClient#12 and #13 via #622)
- **Cash shop sales:** the cash shop's limited-time sale list refreshes correctly on current clients, and removing a sale no longer leaves the server pointing at freed memory, which could crash the map server. Thanks @Dizzzlectic. (rathena#55 and #58 via #628)
- **Roulette:** rewards land on the level they're configured for even when a row is skipped, and reopening the roulette after a losing spin shows the right prize. Thanks @Dizzzlectic. (rathena#56 and #57 via #628)
- **Store search:** results for vending shops show the items' random options. Thanks @Dizzzlectic. (rathena#59 via #628)

## Known issues
- Client fixes merged since 1.6.3, including the Druid client support, are not in this release yet; they arrive with the next client update.
