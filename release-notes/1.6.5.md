Episode 19 arrives with its maps, monsters and quests, mods get Lua player hooks, and friends playing over the internet load faster and stay connected.

## New
- **Episode 19:** the Episode 19 maps, monsters, NPCs, quests and items from rAthena are in the game, and navigation knows its new monsters, NPCs and warps. Thanks @LilArt420. (rathena#53 via #630)

## Modding
- **Lua player hooks:** a mod's Lua can now decide what a player's base stats count for (a soft cap, for instance) with `player({ base_stat = ... })`, and which DEX the cast-time and skill-delay formulas read with `cast_dex`, including renewal's variable cast time. With no hook, nothing changes. Thanks @BlaXun. (rathena#62 via #630)

## Fixes
- **Starting the game waits for the servers to really be ready:** start-up and restarts could say the game was ready while the character server hadn't yet signed in to the login server, so the first login could fail. The app now waits for both, and a server that has stopped fails the start instead of hanging. Thanks @Dizzzlectic. (#624)
- **Friends load faster when they come back:** a friend playing over the internet no longer downloads every game file again on each visit. Their browser keeps the files and only checks they haven't changed, so a returning friend starts in a few seconds. Thanks @akreao. (#599)
- **Friends stay connected:** the sharing tunnel now runs over HTTP/2 instead of QUIC, which dropped the connection every few minutes during long sessions and left a friend "disconnected from server". Thanks @akreao. (#602)

## Known issues
- **A saved buff can come back as a different one, once:** Episode 19 adds a status in the middle of rAthena's list, so a buff a character had at logout from the statuses after it comes back once as a different status after updating. It happens only this once. (rathena#53)
